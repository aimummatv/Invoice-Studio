# 3.0.1 - 26 October 2026

Invoice Studio is now a bundled offline Windows desktop app with an installer and portable executable. Existing Magic Roots workstation styling, document tabs, favourites, themes, live preview and messenger workflows are retained.

SQLite replaces browser-origin localStorage/JavaScript persistence. Draft save now writes to disk; issued snapshots are protected. Document numbers, credits, payment allocations, backups and imports are transactional. Samples are backed up and fresh installations start empty.

Adds mixed taxes, fractional quantities, decimal arithmetic, original-rate partial credits, recorded advances, Bill of Supply, reviewed tax rules, batch/licence/readiness fields, registers/ageing/reports and optional stock (disabled).

Replaces raster/forced-one-page exports with paginated searchable PDFs. Adds local fonts/styles, appearance presets, three copies, actual Excel template/export/import preview, atomic file saving, backup/restore and recovery.

Executables are unsigned. Online GST services and statutory filing validation are not configured. See TEST_REPORT.md for checks and limitations; README.md explains data locations and recovery.
